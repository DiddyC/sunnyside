# Shady Seat (formerly Sunny-Side)

Which side of the train, bus, car, plane or ferry will be in the shade? Shady Seat tells you in one word. Enter where you're going and when you leave; it follows the route minute by minute, works out where the sun is, scores the glare through each side window, and says LEFT or RIGHT, with a sun compass you can scrub through the trip.

iOS 17+, SwiftUI, no backend, no accounts. Place search runs on Apple Maps. See `docs/` for the algorithm, setup and release tooling.
